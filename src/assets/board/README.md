# Board Member Images

Place board member photos here with the following naming convention:

```
board-{name}.jpg
```

Replace spaces with hyphens and use lowercase.

Examples:
- board-dominic-kapalu.jpg
- board-liversage-hanene.jpg
- board-charity-k-banda.jpg
- board-christopher-odonel.jpg
- board-sylvia-k-masabo.jpg
- board-francis-chilunga.jpg

Recommended resolution: 400x500px (4:5 aspect ratio)
Format: JPEG or WebP
Max file size: 100KB
