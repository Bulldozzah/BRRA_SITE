# Management Team Images

Place management team photos here with the following naming convention:

```
management-{name}.jpg
```

Replace spaces with hyphens and use lowercase. Remove periods from initials.

Examples:
- management-sharon-ck-sichilongo.jpg
- management-david-s-banda.jpg
- management-david-f-banda.jpg
- management-dennis-kamfwa.jpg
- management-nyantanga-chibwe.jpg
- management-richard-e-chanda.jpg
- management-joel-mumba.jpg

Recommended resolution: 300x375px (4:5 aspect ratio)
Format: JPEG or WebP
Max file size: 60KB

Note: Executive Director can use larger size (400x500px) for prominence
